# Règlement CADEV 2026 - points qui engagent l'équipe (lu le 2026-10-08)

- **Dates (heure de Dakar)** : inscriptions + soumission jusqu'au **31 oct 2026 à 17 h 00** (aucune exception). **Vote des paires : 1er-2 nov : chaque membre de l'équipe DOIT voter, sinon le projet est EXCLU** (art. 7). Vote public + jury : 4-10 nov. Résultats : 15 nov.
- Équipe de **2 à 5** membres, tous majeurs, compte Datacloud, pays éligibles (Sénégal inclus). Un représentant unique + clé de répartition du prix.
- **Recevabilité** : projet déployé en ligne ; **au moins 1 produit/service Datacloud acheté** (code promo -70 %) ; création **originale réalisée pendant le Concours** (un projet antérieur est interdit) ; déclaration de titularité de chaque membre (pas de mission employeur/école). Code antérieur d'un membre : autorisé **s'il est déclaré**.
- **Licences** : permissives (MIT, Apache 2.0, BSD) ; **GPL/AGPL/LGPL = irrecevable**. Tous les composants et licences sont à déclarer (`LICENSES.md`).
- **IA** : libre mais **déclarée à la soumission** (outils + parties concernées) (`AI_USAGE.md`). Le jury note la **maîtrise de l'équipe** du code livré, y compris produit par IA, et sa capacité à l'expliquer : **chaque membre doit pouvoir expliquer l'architecture** (`ARCHITECTURE.md`, `DEMO.md`).
- **Notation** : pertinence 25 % · qualité technique (architecture, robustesse, sécurité, code, maîtrise, licences) 30 % · UX 20 % · innovation 15 % · vote public 10 %.
- **Prix** : 5 000 000 FCFA brut, **conditionné à la cession exclusive** à Systalink des droits patrimoniaux (code, base, documentation, graphisme) : le lauréat ne pourra plus exploiter la solution. Les non-lauréats gardent leurs droits (licence d'affichage 12 mois).
- Fraude (comptes multiples, manipulation des votes, plagiat, code antérieur) = disqualification.
